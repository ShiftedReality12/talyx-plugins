# Talyx plug-ins for Claude Code

Free Claude Code plug-ins from [Talyx AI](https://talyx.ai). We help advisors and professional-services firms build compounding intelligence from what they already know.

## Install

```
/plugin marketplace add talyx-ai/talyx-plugins
/plugin install pcp@talyx
python3 format/talyx_pdf.py --setup      # once per machine, from the plug-in folder
```

## Plug-ins

| Plug-in | What it does |
|---|---|
| [`pcp`](plugins/pcp) | Pre-call prep (v2). Calibrates once, researches public sources with a coverage ledger, and produces one 3-page PDF: a 2-page brief and a 1-page meeting script, with every fact cited. |
